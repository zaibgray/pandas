# Pandas Notebook

This is my personal notebook where I'm learning Pandas. I made it mainly for myself, but sharing it here in case it helps someone else too.

It's a collection of notes and code examples covering the Pandas concepts I use most often for **Data Science, Data Analysis, and AI/ML**.

## What's inside

* **Series** — creating Series, attributes, indexing, selecting values, statistics, missing values, sorting, and common methods
* **DataFrames** — creating DataFrames, attributes, selecting rows and columns, filtering, and inspecting data
* **Data Cleaning** — handling missing values, duplicates, data types, replacing values, and basic transformations
* **Statistics & Analysis** — `mean`, `median`, `min`, `max`, `sum`, `std`, `var`, `quantile`, and descriptive statistics
* **Indexing & Selection** — `loc`, `iloc`, `at`, `iat`, boolean filtering, `isin`, and `query`
* **Grouping & Aggregation** — `groupby`, `agg`, `aggregate`, and `transform`
* **Sorting & Ranking** — `sort_values`, `sort_index`, `nlargest`, `nsmallest`, and `rank`
* **Combining Data** — `merge`, `join`, `concat`, and related operations
* **Reshaping Data** — `pivot`, `pivot_table`, `melt`, `stack`, `unstack`, and `explode`
* **Working with Text** — common `.str` operations such as `lower`, `upper`, `strip`, `contains`, `replace`, and `split`
* **Working with Dates** — `to_datetime` and common `.dt` operations
* **Feature Manipulation** — `shift`, `diff`, `pct_change`, cumulative functions, and `rolling`
* **Data Types** — `astype`, `convert_dtypes`, and `select_dtypes`
* **Conversion & Export** — converting Pandas objects to NumPy, lists, dictionaries, CSV, Excel, JSON, and other formats

(This list matches roughly what's in the notebook — update it if you add more topics.)

## How to use it

1. Clone the repo:

```bash
git clone https://github.com/zaibgray/pandas.git
cd pandas
```

2. Install Pandas and Jupyter (if you don't have them):

```bash
pip install pandas jupyter
```

3. Open the notebook:

```bash
jupyter notebook
```

Then just run the cells one by one.
